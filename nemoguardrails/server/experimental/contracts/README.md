# Experimental guarded provider contracts

The [Guardrails Overlay Profile](guardrails-overlay-profile.md) defines the experimental interchange boundary for guarded provider operations. It separates standard OpenAPI Overlay actions, standard OpenAPI and JSON Schema structure, and the `x-nemo-guardrails` semantics interpreted by NeMo Guardrails.

Provider source descriptors and operation contracts are introduced with their provider capabilities in later stacked pull requests.
